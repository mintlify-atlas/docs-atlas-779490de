Logic Assignment is a C++ program that takes a propositional logic formula — entered directly as an infix string or loaded from a DIMACS CNF file — builds a binary expression tree, and lets you inspect it through multiple traversal orders, height computations, and a complete truth table.

## What it does

<Steps>
  <Step title="Parse a formula">
    Supply an infix propositional formula like `(A+B)*~C` or point the program at a DIMACS `.cnf` file. The lexer tokenises every variable name, operator, and parenthesis.
  </Step>
  <Step title="Build the expression tree">
    The tokens are converted to prefix (Polish) notation and then used to construct a binary tree whose internal nodes are operators and whose leaves are propositional variables.
  </Step>
  <Step title="Traverse and measure the tree">
    Print the tree in pre-order, in-order, and post-order — each available in both recursive and iterative form — and read off the tree height by either method.
  </Step>
  <Step title="Generate the truth table">
    Every combination of truth values for the formula's variables is evaluated against the tree, producing a fully formatted truth table printed to standard output.
  </Step>
</Steps>

<Note>
  Truth table generation is capped at **16 variables** (2¹⁶ = 65,536 rows). Formulas with more variables will display a friendly skip message rather than hanging.
</Note>
